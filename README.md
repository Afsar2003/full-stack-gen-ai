# 🤖 Full Stack Gen AI - Interview Preparation Platform

An AI-powered full stack web application that helps job seekers prepare for
interviews smarter and faster.

## ✨ Features

- 📄 **Resume Analysis** — Upload your resume and let AI analyze your profile
- 🎯 **Job Match Score** — See how well your profile matches the job description
- ❓ **Technical & Behavioral Questions** — Get personalized interview questions
  with answers and intentions behind each question
- 🧠 **Skill Gap Analysis** — Identify missing skills with severity levels
- 📅 **Day-wise Preparation Plan** — Follow a structured preparation plan
  tailored to your profile
- 📝 **AI Resume Generator** — Generate a job-tailored, ATS-friendly resume PDF

## 🛠️ Tech Stack

**Frontend**
- React.js
- React Router
- SCSS

**Backend**
- Node.js & Express.js
- MongoDB & Mongoose
- Google Gemini AI
- Puppeteer (PDF generation)
- Multer (file uploads)
- JWT Authentication
